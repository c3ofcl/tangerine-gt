# Tangerine Gradient Tool

ブラウザからメッシュグラデーションを直感的に生成・調整できるクリエイティブツールです。
フィルムノイズの付加、アスペクト比の無制限変更、最大4倍の高解像度PNGファイルの書き出し、Web実装に役立つCSS/SVGコード生成に対応しています。

---

## 主な機能

* **メッシュグラデーション生成**: 滑らかに合成されたグラデーションを画面右側（モバイルデバイスでは上側）のキャンバスで確認
* **フィルムノイズ調整**: 粒状のノイズ付加と、1〜100%の強度調整（スライダーを利用）
* **柔軟なアスペクト比設定**:
  * プリセット比率（1:1 / 4:3 / 16:9）および縦横反転切り替え
  * 任意のサイズ指定（ピクセル単位で幅と高さカスタマイズ）
* **高解像度な画像生成**: 標準(1x)、高画質(2x)、超高画質(4x)のPNG画像書き出し
* **Webデザイン用コード生成**: 生成したグラデーションをワンクリックでCSS（ノイズ有効時はインラインSVGフィルター付き）としてクリップボードへコピー

---

## 使い方

静的Webアプリケーションのため、Node.js等の環境構築やビルド作業は不要です。

リポジトリをクローンまたはダウンロードした後、`index.html`を任意のローカルサーバー（Live Previewを推奨）で起動してください。

HTMLファイルを直接ブラウザで開いた場合、一部が正常に動作しない場合があります。

```bash
# クローン例
git clone [https://github.com/c3ofcl/tangerine-gg.git](https://github.com/c3ofcl/tangerine-gg.git)
cd tangerine-gradient-tool

# ローカルサーバー起動例 (Pythonの場合)
python -m http.server 8000
